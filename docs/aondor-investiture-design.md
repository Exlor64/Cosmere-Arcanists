# AonDor Investiture access — accepted design (2026-11-06)

Status: implemented locally in0.65.0; full Minecraft CI pending. See [access controls](aondor-access-controls.md) and [provider API](aondor-investiture-api.md). Sel world generation and physical external sources remain deferred.

- On Sel, Elantrians access the Dor directly. It is effectively unlimited; no personal reserve, regeneration timer, personal expenditure or Dor meter is needed there.
- Away from Sel, Elantrians normally cannot use AonDor. They need effective Connection to Sel at least **3× their normal unboosted Connection** AND an eligible external Investiture supply. The reference is the current unboosted baseline before temporary boosts, not a recursively increasing threshold based on the already-boosted value. These are independent requirements: fuel alone does not enable casting, and Connection alone does not supply ambient Dor off-world. Failure of either requirement must prevent effects.
- All spell actions and functional modifiers still have dynamic work/cost requirements. Unlimited ambient Dor satisfies them on Sel; finite external sources must pay them elsewhere.
- Price resolved effective magnitude/power, actual unique targets/blocks, duration, brightness/permanence and processed item units. Skip defaults are not free. A power0 Heat spell can still perform priced thawing/melting.
- Check Connection/access, resolve and validate the whole spell, select a source and secure payment before mutation. Never partially execute an unaffordable spell or remove learned Aons/power attributes when access is unavailable.

Implemented: a server-owned Investiture access/source layer with an unlimited Sel provider and an external-source integration contract. Specific external sources, storage units, rates, conversions and payment/refund behavior remain undecided. Do not invent personal Elantrian reserves or automatically let a particular metalmind/fuel substitute. The user explicitly added high off-world Connection as a required access gate, superseding the earlier decision to defer cross-world Connection restrictions. The threshold is now3×baseline. Any power that actually boosts the relevant Connection can contribute: feruchemical duralumin, Bondsmith abilities, and later timed AonDor self-Connection spells. Use a shared Connection measurement/provider layer, not a hardcoded whitelist or special duralumin-only unlock. Respect the effective result and each source's own duration/stacking rules; this decision does not define a new additive/multiplicative stacking formula. A numeric planetary ledger is still absent: existing Sel art/Connection is normalized to1 until a provider supplies a real baseline. Zero baseline fails closed. Existing funded duralumin and timed self-boosts are integrated; other powers integrate later. Access loss around payment aborts before effects and refunds committed resources. No automatic tapping-level shortcut is used. Connection must be revalidated when the spell executes.

Cost estimation is still useful for future external sources, even though Sel does not drain a personal pool. Numeric comparisons and saved spell layouts remain separate future language/UX work.

Future timed AonDor Connection boosts may sustain off-world eligibility for their duration, provided external Investiture remains available. Such a spell still needs ordinary casting eligibility when cast; it does not provide an implicit bypass when the user already lacks access. This is an implementation inference, not a separately specified bootstrap exception.
